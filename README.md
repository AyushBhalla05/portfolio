# 🌐 Personal Developer Portfolio

> Modern, responsive developer portfolio built with Next.js, TypeScript, and Tailwind CSS to showcase my projects and technical skills.

🔗 **Live Website:** [https://portfolio-seven-dun-86.vercel.app](https://portfolio-seven-dun-86.vercel.app)

---

## ✨ Features
- ⚡ **High Performance & SEO Optimized** using Next.js App Router
- 🎨 **Modern Glassmorphic UI** with Dark Mode support
- 📱 **100% Responsive** across mobile, tablet, and desktop screens
- 📬 **Interactive Contact Section** & Project Showcases

---

## 🛠️ Tech Stack
- **Framework:** Next.js / React.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
